# ヤフオク入札予約

ヤフオク（Yahoo!オークション）の商品を「**終了◯秒前に、◯円で入札**」と予約しておくと、時間になったら自動で入札するブラウザ拡張です。
終了2分前・30秒前など、自分で決めたタイミングで入札できます。

- 商品ページの右下に「入札予約」パネルが出て、そこから予約
- 入札金額は最低入札額から始まり、＋－で入札単位ぶん上げ下げ
- ツールバーのアイコンで、どのページにいても予約一覧・残り時間・取り消し・記録を確認
- 終わったら Windows / Mac の通知でお知らせ
- **練習モード**：最後の「入札する」だけ押さずに止まる（動作確認用）

## 使える環境

| | Windows | Mac | iPhone | Android |
|---|---|---|---|---|
| Chrome・Edge・Brave など | ○ | ○（未確認） | ✕ | ✕ |
| Firefox | △（未確認） | △（未確認） | ✕ | ✕ |

- **PCで、ブラウザを開いたまま**使う道具です。予約した時刻にブラウザが動いている必要があります。
- スマホは、ブラウザを開きっぱなしにできず予約の時刻に動けないため対象外です。
- 動作確認済み：Windows 11 ＋ Edge（2026年11月の実際のヤフオク画面で、練習モードが最後のボタンの手前まで通ることを確認）。

## 入れ方

### Chrome・Edge・Brave など
1. [Releases](../../releases/latest) から `YahuokuNyusatsuYoyaku.zip` をダウンロードして展開
2. Edgeなら `edge://extensions`、Chromeなら `chrome://extensions` を開く
3. 「開発者モード」をオン
4. 「展開して読み込み」（Chromeは「パッケージ化されていない拡張機能を読み込む」）で、展開したフォルダを選ぶ
5. 右上のパズルのマークから「ヤフオク入札予約」をピン留めしておくと、一覧がすぐ開けます

### Firefox（未確認）
1. [Releases](../../releases/latest) から `YahuokuNyusatsuYoyaku-firefox.zip` をダウンロード
2. `about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む」→ ZIP を選ぶ
   （一時的な読み込みは Firefox を閉じると消えます）

## 使い方
1. ブラウザでヤフオクにログインしておく
2. 欲しい商品のページを開くと、右下に「入札予約」パネルが出る
3. 金額・タイミング（5分前〜15秒前、または秒数指定）を選んで「予約する」
4. ツールバーのアイコンで予約一覧・残り時間・取り消し・記録が見られる

入札時刻の約90秒前に、その商品を新しいタブで開きます。12秒前に入札画面を開いて金額を入れ、指定の時刻ちょうどに最後の「入札する」を押します。

## 最初は必ず「練習モード」で
練習モードは最後の「入札する」だけ押さずに止まり、そのボタンをオレンジの枠で示します。本番の前に、自分の環境でも練習モードで1回試してください。
ヤフオクの画面が変わると動かなくなることがあります。うまくいかないときは、一覧の「記録」を見てください。

## 注意
- **PCとブラウザは開いたままに。** 予約中はスリープを自動で止めます（Chrome・Edge）。ブラウザを閉じると入札できません。
- **PCの時計がずれていると入札時刻もずれます。** 時刻を自動で合わせる設定にしておいてください。
- **自動延長「あり」の商品**は、終了5分前以降に入札があると5分延びます。延長後に再入札はしないので、競り負けることがあります。
- 入札直前に最低入札額が予約金額を上回っていたら入札しません。
- クーポンなどのお知らせが出ていたら自動で閉じてから入札画面に進みます。
- 終了時刻を過ぎた商品では予約できません。
- **落札したら購入の義務があります。** 金額は落札してもいい上限で。
- ヤフオクの利用規約・ガイドラインは変わることがあります。使う前に確認し、自己責任で使ってください。このツールはヤフオク（LINEヤフー株式会社）とは関係ありません。

## しくみ・安全性
- 通信するのはヤフオクのページだけです。外部のサーバーにデータを送ることはありません。
- 予約の内容はブラウザの中（拡張機能の保存領域）にだけ保存されます。
- パスワードやカード情報には一切さわりません。ログインはブラウザに任せています。
- 使う権限：保存（storage）、時刻の予約（alarms）、通知（notifications）、スリープ防止（power）、ヤフオクのページ（`*.auctions.yahoo.co.jp`）だけ。

## 新しい版の出し方（開発者向け）
